# Samples Overview

| [Character Presets](/samples/presets) | Numeric, letters, custom character sets |
| [Theming](/samples/theming) | Light, dark, and auto theme modes |
| [Distortion](/samples/distortion) | None, lines, dots, or both |
| [Accessibility](/samples/accessibility) | ARIA labels and audio support |
| [Custom Icon](/samples/custom-icon) | Custom refresh icon slot |
| [Audio Support](/samples/audio) | Speak captcha code for screen readers |

| [Form Integration](/samples/form-integration) | Form with captcha validation |
| [Simple Mode](/samples/simple-mode) | Clean, straight-line text |
| [CSS Variables](/samples/css-variables) | Custom theming via CSS variables |
